# Portfolio BTS SIO SISR — Christophe Valmond Fontana

## Aperçu local
Ouvrir `index.html` dans un navigateur. Aucun outil de compilation n'est nécessaire.

## Publication avec GitHub Pages
1. Créer un dépôt GitHub nommé `portfolio` (ou `valmondcf.github.io`).
2. Ajouter `index.html`, `style.css` et `script.js` à la racine du dépôt.
3. Dans GitHub : Settings → Pages.
4. Choisir `Deploy from a branch`, branche `main`, dossier `/ (root)`, puis Save.
5. Attendre la publication. Pour un dépôt `portfolio`, l'adresse sera généralement :
   `https://valmondcf.github.io/portfolio/`

## Avant de présenter au jury
- Compléter les fiches projets avec les réalisations réellement effectuées.
- Ajouter des captures d'écran, schémas réseau et procédures, en masquant les données sensibles.
- Ajouter éventuellement le CV PDF dans ce dossier et un lien vers celui-ci.
- Vérifier les dates et informations personnelles.
- Ne pas publier de mots de passe, adresses IP publiques sensibles, configurations confidentielles ou données d'établissement.

Le site utilise Google Fonts via Internet. Les polices système restent disponibles si le service est inaccessible.
